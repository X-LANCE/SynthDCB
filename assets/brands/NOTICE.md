# Brand assets

The Claude, DeepSeek, Gemini, Gemma, Hugging Face, OpenAI, Qwen and Z.ai marks come from `@lobehub/icons-static-svg` 1.103.0. The accompanying license covers the icon files. [Lobe Icons](https://github.com/lobehub/lobe-icons) · [MIT license](LICENSE-lobe-icons.txt)

The framed picture emoji is from Twemoji by Twitter and contributors, cropped and resized for the menu. [Twemoji](https://github.com/jdecked/twemoji) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

The MobA and Image Edit Agent menu icons are cropped from the title images in their official repositories. [MobA](https://github.com/OpenDFM/MobA/blob/HEAD/assets/title.png) · [Image Edit Agent](https://github.com/OpenDFM/Image_Edit_Agent/blob/HEAD/assets/title.png)

The OpenBMB mark is the organization's public GitHub avatar. [OpenBMB](https://github.com/OpenBMB)

The GitHub glyph comes from Font Awesome Free 5.15.1 by Fonticons. The arXiv glyph is the Academicons font outline by James Walsh and Katja Berčič, converted to SVG. [Font Awesome](https://fontawesome.com/v5/icons/github) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) · [Academicons](https://jpswalsh.github.io/academicons/) · [Font licenses](LICENSE-resource-fonts.txt)

The local emoji fallback contains the hugging face and page with curl glyphs from Google’s Noto Color Emoji font. [Noto Emoji](https://github.com/googlefonts/noto-emoji) · [Font licenses](LICENSE-resource-fonts.txt)
